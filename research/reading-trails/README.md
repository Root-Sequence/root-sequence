# Reading Trails

**Document role:** Curated research-rabbit-hole index  
**Status:** Developing  
**Purpose:** Preserve the sites, archives, societies, reading lists, courses, magazines, papers, and other intellectual neighborhoods that surface during Root Sequence research.

## Why this exists

A bibliography answers:

> What source supports this claim?

A Reading Trail answers a different question:

> **Where can someone go wander, learn the field's language, discover adjacent ideas, and find things we did not already know to search for?**

Root Sequence research repeatedly encounters valuable resources that are not themselves the canonical evidence for a claim:

- old specialist magazines;
- scholar-maintained archives;
- societies and conference proceedings;
- reading lists;
- course platforms;
- historical collections;
- research-community wikis;
- practitioner notes;
- repositories of talks and workshops.

Those are easy to lose when only the final paper citation survives.

Reading Trails preserve them.

## Rules

A Reading Trail should distinguish:

- **primary / scholarly source** — use for claims when appropriate;
- **reference / overview** — useful for orientation and terminology;
- **archive** — valuable historical/source material;
- **community / society** — people, events, current work, bibliographies;
- **learning hub** — courses/tutorials;
- **practitioner resource** — useful synthesis whose authority must still be checked;
- **rabbit-hole site** — high discovery value even when it is not itself evidence.

Do not treat inclusion as endorsement or validation.

Do not replace claim-level evidence with a cool website.

- alternative institutions / abandoned futures;

Keep these **curated**, not exhaustive link dumps.
