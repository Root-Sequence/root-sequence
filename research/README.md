# Research syntheses

This directory holds versioned papers that synthesize Root Sequence's existing research. It does not replace the canonical treatments in `concepts/`, `systems/`, `analysis/`, or `futures/`.

## Living papers

- [Coherence Is a Systems Property](papers/coherent-systems/README.md) — **v0.1-dev; AI-assisted working draft; author review pending**. Charter, annotated argument, claims ledger, source map, and research questions. Not a reviewed release or a validated theory.

A paper proposes a synthesis; the underlying research can contradict and revise it. Do not move material into this directory merely to make the paper appear comprehensive.

## Publication boundary

Public branches and pull requests in this repository are public. They are not private review spaces. Only public-safe synthesis belongs here; private notes and unpublished fiction retain their existing homes and permissions. Website presentation is separate and requires an explicit publication pass.
