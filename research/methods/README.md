# Research Methods

**Status:** living / organization-level methods  
**Scope:** shared inquiry practices that projects may translate locally without treating them as automatic answers

Root Sequence uses methods as **error-correcting infrastructure**. A method should help a project notice missing perspectives, weak evidence, manufactured agreement, premature certainty, or a model that no longer survives contact with reality.

Current shared methods:

- [Epistemic Contrast](epistemic-contrast.md) — deliberately compare situated accounts, roles, assumptions, mechanisms, and evidence without treating disagreement itself as balance.
- [Deliberative Inquiry](deliberative-inquiry.md) — build sufficient shared understanding before consequential collective judgment or authorization.

These methods complement, rather than replace, discipline-specific methods. A claim about economics, ecology, cognition, law, medicine, engineering, or any other field should still be routed to the strongest relevant methods and evidence in that field.

## Working loop

```text
question / observation
        ↓
epistemic contrast
        ↓
evidence + native methods
        ↓
shared model / uncertainty map
        ↓
deliberation where collective judgment is needed
        ↓
action / experiment
        ↓
observed consequences
        ↓
revision
        ↺
```

A compact orientation is:

> **Reality gets veto power.**

This is shorthand for corrigibility, not a claim that evidence is simple, perspective-free, or always immediately available. Models remain provisional; stronger evidence, better methods, counterexamples, and affected perspectives can require revision.
