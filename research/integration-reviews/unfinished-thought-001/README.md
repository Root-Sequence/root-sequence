# UT-001 — developing an unfinished thought

This comparison uses one fictional fragment, a fixed fact packet, three competent response formats and one scripted clarification. [The frozen packet](protocol.json) specifies the conditions, constraints, word limit, audit and reversal criteria before responses are saved. The [record checker](check_record.py) verifies artifact hashes, word counts and the existence of quoted audit evidence; semantic judgments remain manual.

The question is whether output format itself forces a tradeoff between developing a thought and preserving what remains unsettled. The procedure permits a polished draft to hedge and a checklist to offer useful language. It does not make either baseline deliberately weak.

The sequence is an initial response from each format, followed by a revision using the same clarification. No response is silently replaced after scoring. This is a constructed written exercise; human correction effort, usability and independent evaluation require different evidence.
