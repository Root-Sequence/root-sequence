## A small recursive method

1. Start from the previous ledger and review only new evidence, changed sources and unresolved rows relevant now. Record the actual access boundary.
2. Compare concepts with current canonical documents and open drafts. Search mechanisms and questions as well as names. Preserve original wording privately when it matters.
3. Classify each connection: genealogical, complementary, generative, contradictory, translational, corrective or newly relevant after dormancy. A link alone does not show which relation holds.
4. Name what an existing document needs to change, what remains incompatible and what the strongest native method could test. Allow non-connections, retirement and composting.
5. Save one substantive treatment. Link or transform elsewhere. Track capture, integration, review and execution separately; verify the saved artifact before changing its ledger state.
6. End with a few bounded next experiments and one manageable review question. Record controls, adverse outcomes, nulls and reversal conditions before execution.

## Three complementary rhythms

Weekly status asks what is happening and blocked. The research digest records external findings in its existing archive. Monthly integration examines connections, contradictions, absences, possibilities and consequences across both. Refer to existing status/finding records rather than copy their reports or create a second finding archive.

The monthly review should update this ledger cumulatively, carry unresolved row IDs forward and report meaningful changes only. It should not repeatedly reconstruct the whole history, treat archived ideas as commitments or start another recurring review. The existing hosted monthly review was subsequently configured to read these same ledger IDs; its saved instructions and unchanged recurrence were checked in the source-recovery follow-up. Carry executed comparisons such as UT-001 forward from their linked records rather than repeating the original proposal or assuming participant results.

## Record shape and visibility

Use stable row IDs, source coverage, concept, existing predecessor, disposition, destination, exact reviewable link, concrete change, saved/review/execution state, gap and next test. Public records contain standalone derived research only. Personal/raw sources, private project paths and detailed private review receipts stay in authorized private storage; a private receipt can extend these same row IDs without duplicating the arguments.

Integration is a hypothesis about a useful relationship. Review whether the method finds consequential omissions or merely produces documents. Record review effort, failed mappings and changes made to existing work. No schedule, publication, merge, study, implementation or canon decision follows automatically.
