# Example: Harmful Relationship Dynamics

This example applies core system principles to a common pattern: abusive or harmful relationships.

## Asymmetry

One person shapes conditions:
- introduces instability (fear, control, unpredictability)

The other adapts:
- tries to stabilize
- makes sense of behavior
- attempts to restore connection

These roles are not equivalent.

## Misclassification

The dynamic is often mislabeled:

- control -> "love"
- jealousy -> "care"
- volatility -> "passion"

This makes the system appear normal or meaningful rather than harmful.

## Feedback loops

The pattern sustains itself through cycles:

- harm -> confusion -> apology -> relief -> attachment

Intermittent reward strengthens the attachment over time.

## Reinforcement

What gets reinforced:

- staying is reinforced by moments of relief
- harm is reinforced if it does not lead to lasting consequences

Over time:

reaction -> repetition -> reinforcement -> belief ("this is love") -> system

## Compression vs expansion

After moments of clarity:

Compression:
- "it's not that bad"
- "they didn't mean it"
- stabilizes quickly

Expansion:
- "this is harmful"
- "this pattern keeps repeating"
- requires change

Compression is more likely when:
- leaving is costly
- support is limited
- instability is overwhelming

## Key insight

The persistence of the system is not based on truth.

It is based on what is repeated and reinforced.

## Questions

- what is actually being reinforced here?
- what would need to change for a different pattern to stabilize?
