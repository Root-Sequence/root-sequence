# Relationship systems

**Document role:** Local index<br>
**Status:** Developing<br>

This area uses systems lenses to examine recurring relationship dynamics while preserving individual context, agency, responsibility, and safety. A structural pattern is not a diagnosis of a person or a substitute for direct support.
