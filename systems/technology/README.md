# Technology systems

**Document role:** Local index<br>
**Status:** Developing<br>

This area treats technology as a material, institutional, economic, and social system rather than as isolated tools. Technical behavior, ownership, labor, infrastructure, governance, and affected people all remain part of the system boundary.
