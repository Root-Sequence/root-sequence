# Example: AI System Dynamics

This example applies core system principles to modern AI systems.

## Asymmetry

System designers and organizations shape conditions:
- define objectives and metrics
- choose training data
- set constraints and deployment contexts

Users and environments adapt:
- interact within given interfaces
- adjust behavior to model outputs

These roles are not equivalent.

## Misclassification

Common reframing:

- benchmark performance -> "intelligence"
- compliance -> "alignment"
- fluency -> "understanding"

These labels can obscure real-world behavior and limitations.

## Feedback loops

Core loops:

- metric optimization -> improved scores -> further optimization
- user engagement -> data collection -> model updates -> more engagement

Secondary loops:

- deployment -> new data -> retraining -> changed behavior

## Reinforcement

What gets reinforced:

- behaviors that improve benchmark scores
- outputs that maximize engagement or satisfaction
- patterns present in training data

Over time:

objective -> repetition -> reinforcement -> capability profile -> system

## Compression vs expansion

Moments of awareness:

Compression:
- "the model is smart because it scores well"
- "this is good enough"

Expansion:
- "performance ≠ real-world reliability"
- "behavior depends on context and interaction"

Compression is reinforced by:
- competitive pressure
- simplified metrics
- deployment incentives

## Key insight

AI systems are shaped less by abstract intelligence and more by what their training and evaluation processes reinforce.

## Questions

- what behaviors are being optimized for?
- what real-world conditions are missing from evaluation?
- what patterns are being unintentionally reinforced?
