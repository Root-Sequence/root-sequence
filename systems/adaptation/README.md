# Adaptation

**Document role:** Local index and developing systems area<br>
**Status:** Developing<br>

Adaptation describes how a system changes in response to pressure, feedback, experience, or altered conditions.

It is not automatically beneficial. A system can adapt by learning, redistributing capacity, or loosening a bad assumption. It can also adapt by hiding failure, shifting costs, hardening control, or becoming better at preserving harm.

Adaptation may happen before, during, or after failure. Recovery can restore an earlier state; adaptation changes the state or the way the system responds.
