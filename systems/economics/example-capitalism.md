# Example: Capitalist System Dynamics

This example applies core system principles to modern capitalism.

## Asymmetry

Certain actors shape conditions:
- capital owners
- corporations
- institutions with control over resources

Others adapt:
- workers
- consumers
- communities

These roles are not equivalent.

## Misclassification

Common reframing of dynamics:

- exploitation -> "opportunity"
- necessity -> "choice"
- survival labor -> "freedom"

These labels make structural constraints appear voluntary.

## Feedback loops

Core loop:

- profit -> reinvestment -> growth -> more profit

Secondary loops:

- precarity -> dependence -> compliance
- advertising -> desire -> consumption -> revenue

## Reinforcement

What gets reinforced:

- profit-maximizing behavior
- cost-cutting (often at human/environmental expense)
- scaling regardless of impact

Over time:

incentive -> repetition -> reinforcement -> norm -> system

## Compression vs expansion

Moments of awareness:

Compression:
- "that's just how the economy works"
- "you have to survive"

Expansion:
- "this system produces harm"
- "alternatives are possible"

Compression is reinforced by:
- financial pressure
- lack of alternatives
- normalization

## Key insight

The persistence of capitalism is not only ideological.

It is structural and reinforced through incentives and repetition.

## Questions

- what behaviors are being rewarded?
- what costs are externalized?
- what alternative patterns could be reinforced?
