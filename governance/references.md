# Stewardship reference notes

**Checked:** 2026-10-22. These sources support the stated legal/technical distinctions; the workflow choices are Root Sequence proposals, not requirements imposed by the sources. This is general information, not legal advice for a particular agreement.

| Source | Relevance / limit |
| --- | --- |
| [Creative Commons CC0 legal code](https://creativecommons.org/publicdomain/zero/1.0/legalcode.en) | Waiver, fallback, irrevocability, and rights outside CC0's scope. |
| [Creative Commons FAQ](https://creativecommons.org/faq/) | Irrevocable grants, rights clearance, separate material, and content-versus-software licensing. |
| [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.en) | Attribution and permitted commercial reuse; deed is a summary, not the complete legal code. |
| [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.en) | ShareAlike obligations for covered adaptations when shared. |
| [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.en) | Noncommercial limitation; not a general harmful-use filter. |
| [GitHub: Licensing a repository](https://docs.github.com/articles/licensing-a-repository) | Public visibility and platform permissions differ from an open-source license. |
| [Open Source Initiative: Open Source Definition](https://opensource.org/osd) | Open-source software licenses cannot discriminate against groups or fields of endeavor. |
| [U.S. Copyright Office: What does copyright protect?](https://www.copyright.gov/help/faq/faq-protect.html) | Expression versus ideas, systems, and methods. |
| [U.S. Copyright Office: NewsNet 1060](https://www.copyright.gov/newsnet/2025/1060.html) | 2025 human-authorship / AI-assistance guidance; not a determination about any RS work. |
| [GitHub: About CITATION files](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files) | Citation metadata and non-software preferred-citation types. |
| [GitHub: Setting repository visibility](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/setting-repository-visibility) | Existing public forks do not become private when the upstream repository does. |

Repository observations are linked separately in the [dated baseline](licensing-audit-2026-10-22.md). A source supporting a general rule does not establish ownership, infringement, novelty, or enforceability in a specific case.
